# OW Tracker 

A simple Overwatch 2 win/loss tracker with an OBS browser overlay.

Built with React, TypeScript and Vite.

## Features

- Track wins and losses
- Automatically calculate win rate
- Stats persist using browser local storage
- OBS-compatible browser overlay
- Keyboard shortcuts
- No backend required
